# ADR-001: Small transactional local prototype

- **Status:** Accepted for assignment prototype
- **Decision:** Use Python standard library HTTP server + SQLite + static HTML/CSS/JavaScript.
- **Context:** The assignment values correctness, reasoning, tests, and an easy local setup over infrastructure complexity.
- **Benefits:** No package installation; local reproducibility; durable state; SQL transactions; inspectable code; fast iteration.
- **Trade-offs:** One application process is the supported deployment model. SQLite and the process-local lock do not provide a complete distributed coordination solution across independent application instances.
- **Safety decision:** Predictive pacing never has a direct provider call path. All requests pass through the Safety Controller, which caps agent-bound calls against current availability.
- **Future work:** Shared Postgres with conditional updates/constraints; provider adapter interface; reservation leases and reconciliation; robust provider health circuit breaker; metrics and structured logs; policy checks for consent, DNC, local calling windows, and abandonment risk; integration and concurrency tests across multiple processes.
